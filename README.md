# FashionVerse — Adaptive AI Fashion Stylist

An intelligent fashion recommendation system powered by Reinforcement Learning (PPO), Generative AI (Gemini), and 3D Virtual Try-On.

## Features
- 🤖 RL-powered outfit recommendations (PPO agent)
- 💬 AI Chat stylist powered by Gemini
- 🪞 3D Avatar Virtual Try-On
- 📊 Real-time analytics dashboard
- 👤 Personalized user profiles

## Tech Stack
- **Backend**: FastAPI + Python 3.11
- **Frontend**: React + Vite
- **RL**: Stable-Baselines3 (PPO)
- **GenAI**: Google Gemini via OpenAI-compatible API
